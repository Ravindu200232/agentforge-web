Drop the four headshots in here, then run:

    npm run team:photos

Name each file so it contains the person's first name, or just number them
1 to 4 in this order:

    1  Ravindu Subasingha
    2  Nimthera Gunasena
    3  Hamna Rahmathullah Hakeem
    4  Malith Bandara

Any format works (jpg, png, webp). The script centre-crops each one to a
square, resizes it to 640x640 and writes it into public/team/ under the
filename the site expects.
